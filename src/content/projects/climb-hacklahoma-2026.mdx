## What it is

Climb is a Pomodoro focus app my team built at Hacklahoma 2026. It rewards focused work
sessions and adds a penalty when you spend time in distracting apps. We built it with Expo,
React Native and TypeScript, and I built both the backend and the frontend. The photo is from the demo, with the app running on a phone and
the code on the laptop.

**Status:** built and demoed at Hacklahoma 2026. The code is on GitHub.
