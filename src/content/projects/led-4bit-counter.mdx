## Introduction

Each LED is one bit of a binary number. The blue Elegoo board only supplies USB power.

## Architecture and components

- **555 timer (astable):** the clock, one pulse per step
- **74HC D flip-flops (x4):** hold the current number, one bit per LED
- **74HC AND, OR and NOT gates:** work out the next number in the sequence
- **4 LEDs:** show the number in binary
